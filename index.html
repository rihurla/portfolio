Guitar Input Monitor

February 2026 - Ongoing

Guitar Input Monitor is a native macOS app that delivers ultra-low latency audio monitoring for guitarists and musicians. Built with Core Audio, it features real-time monitoring with adjustable buffer sizes as low as 0.36ms, a built-in chromatic tuner with visual feedback, multi-channel input support, and menu bar integration. Perfect for home practice, live performance, and music production.

WOut - Weekly Workouts

February 2025 - Ongoing

WOut is a native iOS app built with SwiftUI and SwiftData, following an MVVM architecture for a clean and maintainable codebase. It is designed as offline first, with workouts and plans stored locally and synced through iCloud for fast, reliable use anywhere. HealthKit provides fitness data integration, while Foundation Models and Apple Intelligence power on device workout generation with privacy by default.
